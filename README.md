# לוח בקרה - מפלגה

אתר דשבורד לניהול ומעקב יומי אחר ביצועי כל אחראי תחום במפלגה, עם סיכום שבועי אוטומטי וצבעים לפי עמידה ביעד.

אין תלות בשום ספרייה חיצונית - רק Python 3 (מותקן כבר על המחשב). אין npm, אין build, אין התקנות.

## הרצה מקומית

```bash
cd party-dashboard
python3 seed.py     # פעם ראשונה בלבד - יוצר את בסיס הנתונים עם נתוני הדוגמה
python3 server.py   # מפעיל את השרת
```

לאחר מכן פתחו בדפדפן:
- לוח הבקרה הציבורי: http://localhost:8420/
- טופס העדכון היומי (לאחראים): http://localhost:8420/update

## מבנה הקבצים

- `server.py` - השרת (API + הגשת הדפים)
- `db.py` - חיבור למסד הנתונים (SQLite, קובץ `data.db`)
- `seed.py` - נתוני דוגמה התחלתיים (אפשר לערוך ולהריץ שוב כדי לאפס)
- `static/index.html` + `app.js` - לוח הבקרה
- `static/update.html` + `update.js` - טופס העדכון היומי

## איך מוסיפים/משנים אחראים ומדדים

ערכו את `seed.py`:
- `PEOPLE` - רשימת שמות האחראים
- `METRICS` - לכל אחראי, רשימת מדדים בפורמט `(שם המדד, יעד שבועי או None, בסיס התחלתי)`
- `ENTRIES` - נתוני היסטוריה לדוגמה (אפשר להשאיר ריק לאחראים חדשים - יתמלא דרך טופס העדכון)

לאחר עריכה, הריצו שוב `python3 seed.py` (שימו לב: זה מוחק את הנתונים הקיימים ומחליף אותם. אם כבר יש נתונים אמיתיים שהוזנו דרך האתר, אל תריצו את seed.py שוב - במקום זה אפשר להוסיף אחראים/מדדים ישירות דרך שאילתת SQL, או לבקש ממני להוסיף מסך ניהול לכך).

## פריסה לאינטרנט (כדי שכולם יוכלו לגשת מכל מקום)

השרת המקומי רץ רק על המחשב הזה. כדי שכל חברי המפלגה יוכלו לגשת מהטלפון/מהבית, צריך לפרוס אותו לשירות אירוח. כמה אפשרויות פשוטות וזולות (יש להן שכבה חינמית):

1. **Render.com** / **Railway.app** - מעלים את הקוד (git), מגדירים Start Command: `python3 server.py`, והשירות ניתן לך כתובת ציבורית קבועה.
2. **PythonAnywhere** - מתאים ל-Python, יש שכבה חינמית.

לתשומת לב: ל-SQLite (`data.db`) יש מגבלה בפריסות מסוימות (למשל Vercel) שבהן מערכת הקבצים זמנית ולא נשמרת. Render/Railway/PythonAnywhere עם דיסק קבוע (persistent disk) מתאימים היטב. אם תרצו, אני יכול לעזור בפריסה בפועל ברגע שתבחרו שירות ותחברו חשבון.

## הרשאות

כרגע כל אחד יכול לבחור את שמו ולעדכן נתונים (ללא סיסמה) - נוח לשימוש יומיומי. לוח הבקרה עצמו פתוח לצפייה לכולם. אם תרצו הגנה בסיסמה/PIN אישי לכל אחראי כדי שאף אחד לא יוכל לשנות נתונים של מישהו אחר, אפשר להוסיף את זה בקלות.
